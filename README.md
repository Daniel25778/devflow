# DevFlow

Sistema de gerenciamento de projetos e tarefas para desenvolvedores, com board Kanban, prioridades, tags e um dashboard simples.

> 🚧 Em desenvolvimento — projeto de portfólio construído com **Spec-Driven Development (SDD)**.

## Stack

- [Next.js](https://nextjs.org/) (App Router, TypeScript)
- [Tailwind CSS](https://tailwindcss.com/)
- [Prisma](https://www.prisma.io/) + PostgreSQL
- Deploy: [Vercel](https://vercel.com/) + [Railway](https://railway.app/)

## Sobre o processo

Este projeto foi construído seguindo um fluxo de **Spec-Driven Development**, usando a skill [tlc-spec-driven](https://agent-skills.techleads.club/tlc-spec-driven/) do Tech Leads Club: Specify → Design → Tasks → Execute → Verify. A ideia é documentar o processo, não só o resultado final.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
